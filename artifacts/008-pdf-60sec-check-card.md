# 成果物008｜提出PDF 60秒検品カード v0.1

BONSaY「それってどうやるの？」方法©️ 実運用 No.008 から出荷した公開用成果物。

PDFを「作った」で終わらせず、送信・提出できる状態かを60秒で確認するための検品カード。

## 60秒検品

- [ ] **開く**：提出に使う端末でPDFを一度開けた。
- [ ] **順番**：1ページ目から最後まで並び順が合っている。
- [ ] **向き**：横倒し・上下逆のページがない。
- [ ] **読める**：拡大しなくても主要文字が判別できる。
- [ ] **名前**：ファイル名が `内容_氏名または案件名_日付.pdf` のように識別できる。
- [ ] **中身一致**：古い版・別案件・余計なページが混ざっていない。

## 最後の一問

> 受け取った側が、説明なしで「誰の・何の・最新版か」を判別できる？

YESなら提出候補。NOならファイル名または中身へ戻す。

## 製作仕様

- **媒体**：Notion／印刷カード／スマホメモ。
- **項目数**：6項目固定。変換方法そのものは別手順に分離する。
- **完成検査**：60秒で一周できる／全項目がYES・NOで答えられる／特定アプリのUI変更に依存しない。
- **壊し試験**：別端末で開けない場合は「提出物完成」ではなく「書き出し失敗」へ戻す。
