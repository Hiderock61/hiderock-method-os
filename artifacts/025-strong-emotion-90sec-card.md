# 成果物025｜強い感情 伝達前90秒カード v1.0

BONSaY「それってどうやるの？」方法©️ 実運用 No.025 から出荷した公開用成果物。

強い感情がある時に「送る／黙る」の二択へ飛ばず、**何を変えたいか、何が事実か、何を求めるか、相手と自分に選択余地があるか**を90秒で整理してから、伝達方法を選ぶための1枚カード。

## 何のための道具か

相手への怒り、寂しさ、不満、感謝、謝罪、境界線などを「今どう伝えるか」で止まっている時に使う。

メッセージ送信前、電話前、直接話す前に、90秒で次の4点を1文ずつ言える状態を目指す。

- 今回の目的
- 事実と自分の解釈の違い
- 相手に求めること、または求めないこと
- 今回選ぶ伝達モード

> 対人系の完成は「気持ちを全部言えた」ことではなく、目的と要求が混線せず、双方に次の行動を選べる余地が残った状態。

## 守る制約

- 目的は1つ。
- 事実は最大2点。
- 解釈は最大1つ。仮説として書く。
- 感情は最大2語。
- 要求は0または1つ。
- 伝達モードは4択。
- 追撃は原則その場で追加送信しない。次の判断条件を先に書く。

## 強い感情 伝達前90秒カード

### 0｜0〜15秒　何を変えたい？

**今回伝える目的を1つだけ選ぶ。**

- [ ] 知ってほしい
- [ ] 事実を確認したい
- [ ] 誤解を訂正したい
- [ ] 謝りたい
- [ ] 感謝したい
- [ ] 境界線を示したい
- [ ] 何かを頼みたい
- [ ] 関係や距離を変えたい
- [ ] その他：＿＿＿＿＿＿

**目的を1文で**：＿＿＿＿＿＿

### 1｜15〜35秒　4つに分ける

**事実**：実際に起きたこと。＿＿＿＿＿＿  
**感情**：自分に起きた反応。＿＿＿＿＿＿  
**解釈**：相手の意図についての仮説。＿＿＿＿＿＿  
**要求**：相手にしてほしいこと。なければ「なし」。＿＿＿＿＿＿

解釈には「〜と受け取った」「〜なのかなと思った」を付ける。事実へ昇格させない。

### 2｜35〜50秒　今どこまで言う？

- [ ] **A｜今、全部伝える**
- [ ] **B｜今、最低限だけ伝える**
- [ ] **C｜後で伝える**
- [ ] **D｜今回は伝えない**

Bの場合、今出す1点：＿＿＿＿＿＿  
Cの場合、後で話す条件：＿＿＿＿＿＿  
Dの場合、自分側で次にすること：＿＿＿＿＿＿

### 3｜50〜65秒　選択権チェック

- [ ] 相手が「違う」「できない」「今は話せない」と答える余地がある
- [ ] 自分も、その返答を受けて次の行動を選び直せる
- [ ] 感情を伝えることと、要求を受け入れさせることを分けている

**1つでもNOなら、要求部分を削るかCへ。**

### 4｜65〜80秒　返答耐性チェック

送った後に起きても不思議ではないものへ印。

- [ ] NO
- [ ] 反論
- [ ] 誤解
- [ ] 無反応
- [ ] 返答保留
- [ ] 距離が少し変わる

**今この中のどれかが来ても、追撃せず次の判断へ移れる？** YES／NO

NO → BかCへ落とす。

### 5｜80〜90秒　送信文を3部品だけ作る

**①事実**：＿＿＿＿＿＿  
**②感情または確認**：＿＿＿＿＿＿  
**③必要なら要求1つ**：＿＿＿＿＿＿

基本形：

> 「＿＿があった時、＿＿と感じた。＿＿という意味なのかなと受け取ったんだけど、その理解で合ってる？」

確認後、必要なら：

> 「分かった。そのうえで、次から＿＿してもらえると助かる。」

## 赤信号ゲート

次のどれか1つでも当てはまるなら、**今全部送るを保留**。

- [ ] 事実と相手の意図が区別できていない
- [ ] 目的が2つ以上混ざっている
- [ ] 相手のNOを許容できない要求になっている
- [ ] 無反応を待てず、すぐ追撃するつもりになっている
- [ ] 過去の別件を3件以上まとめて回収しようとしている
- [ ] 今送ることで重大な不利益や危険が増える可能性がある

最後の項目に当たる場合は、このカードだけで処理せず、第三者・専門窓口など別ルートを検討する。

## 会話が進んだ後の分岐

### 相手が意図を訂正した

**解釈だけ修正する。感情が起きた事実まで消さない。**

### 相手がNOと言った

要求を繰り返す前に、境界の両立可能性を見る。

- 条件を変えれば成立する
- 距離・頻度・役割を変えれば成立する
- 両立しない

### 無反応

無反応の意味を即断しない。追撃条件を先に決める。

**再確認する条件／時点**：＿＿＿＿＿＿

## このカードが防ぎたい故障

- 感情が強いほど、相手の意図を事実として断定する
- 「私はこう感じた」と「だからこうしろ」を1文へ混ぜる
- 一度のメッセージで過去の不満を全部回収しようとする
- 相手にNOの余地がない要求を「気持ちの共有」として送る
- 返信がすぐ来る前提で送る
- 無反応を即「拒絶」と解釈して追撃する
- 謝罪、確認、要求、関係終了を同時に入れる
- 今すぐ全部言う／一切言わないの二択しか見えない
