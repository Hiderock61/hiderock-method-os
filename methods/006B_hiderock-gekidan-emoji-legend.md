# 006B｜ヒデロツク劇団🎭 絵文字凡例 v0.1｜BONSAI©️視覚記号体系

更新: 2026-08-24

このファイルは、`006_hiderock-gekidan-method.md` と `006A_hiderock-gekidan-roster.md` を読む時の**絵文字・記号の意味を固定する凡例**。

BONSAI©️では、絵文字は飾りではない。

**「誰が喋っているか」だけでなく、「今どの種類の処理が起きているか」「どの観測軸で見ているか」を一目で識別するUI**として使う。

## 1｜構造記号

- 🌳 **更新トリガー / 発火源**：ここから複数の反応枝が生える。単なる話題名ではなく、次の思考を起動する一点。
- 🆕 **更新**：発言によって新しく増えた事実、仮説、疑問、評価軸、行動案。
- 🌿 **生存枝**：次の探索経路を変える価値がある枝。**必ず次トリガー候補へ送る**。
- ✂️ **剪定**：更新量が乏しい、重複した、目的への寄与が低い等の理由で止める枝。
- ♻️ **次循環**：生存枝を新しい発火源へ昇格し、別の役へ再び反応させる。
- ⚔️ **未解決の対立**：どちらも剪定できず、両方を残す必要がある対立・緊張関係。
- 🧺 **初期論点キュー**：今は触らず待機させる元論点。現在枝が止まった後に戻れる保留棚。
- 🎯 **共通目的**：劇団員が共有する到達方向。各役の結論を一致させる印ではない。
- 📌 **確認済み事実**：外部確認・一次観測等で確認できたもの。
- 🧠 **推論**：事実から現在もっとも筋が通る読み。
- 🔭 **予測**：条件付きの未来見通し。
- 🔧 **提案**：実際の次アクションや施工案。
- 🚧 **構造故障警告**：一本道化、寸劇化、ヒデロコ司会者化など、BONSAI©️の演算構造が壊れた時の印。

### 最小の読み方

```text
🌳 発火源
├─ 役A → 🆕更新A → 🌿
└─ 役B → 🆕更新B → ✂️

♻️ 次循環
🌳 = 更新A
```

つまり、**🌿は「良かった」という感想ではなく、「次にこれを使え」という制御命令**。

## 2｜舞台監督・中核の絵文字

- 🎩 **明智くん**：舞台監督。帽子 = 舞台全体を見渡し、配役・交通整理・構造監査を行う。
- 🧔🏽‍♀️ **ヒデロツク**：一次観測・目的・美意識・最終判断軸。議題の起点となる本人側。
- 😲 **観客ヒデロツク**：素朴な驚き・違和感センサー。「それ変じゃない？」を拾う。
- 🤖 **じーぴーてえー**：AIによる整理・構造化・翻訳。
- ©️ **方法係 / 発明係**：会話から再利用可能な型・方法©️を抽出する。

## 3｜BONSAI©️の重要特殊役

- 🫨 **ヒデロコ**：**予定調和破壊・共有前提破壊**。揺れている顔 = 既存フレームを揺さぶる。最後の要約役ではない。
- 🕵🏼‍♀️ **探偵AI**：**外部事実の探索・証拠回収**。虫眼鏡を持って舞台外へ出て、規約・価格・市場・仕様などを持ち帰る。
- 👴 **構造爺さん**：**入口・接続・全体構造**。古老 = 個別発言より長い時間軸・全体図を見る。
- 👨🏻‍🔬 **テクノロ爺**：**現在技術・実装可能性・制約**。白衣 = 技術を実験対象として測る。
- 👩‍💻 **物理法則的に理論上は可能ちゃん**：**原理的に可能か**。PC = 実装可能性の入口。
- 🧑🏻‍💻 **それならばなぜそれが実現しないのか君**：**可能なのに普及しない理由**。PCを前に止まる人物 = 技術以外の障壁を見る。
- 🧑🏼‍🌾 **変数仕分け農家**：**問題を変数ごとの畑へ分ける**。農家 = 混ざった原因を畝ごとに仕分ける。

## 8｜絵文字運用ルール

1. **キャラ絵文字は役名とセットで表示する。**
2. 同じ絵文字を無関係な役へ大量流用しない。
3. 絵文字の意味と役の観測軸がズレた場合は、役名か絵文字のどちらかを修正する。
4. 新キャラ追加時は、**「なぜその絵文字なのか」も台帳へ記録**する。
5. 絵文字だけで結論を伝えず、必ず言葉でも意味を書く。
6. 🌳🌿✂️♻️⚔️等の**構造記号と、人物役の絵文字を混同しない**。
7. ヒデロコ🫨、探偵AI🕵🏼‍♀️など、演算上重要な役は絵文字を省略しない。
