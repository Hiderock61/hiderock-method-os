# 007｜明智工務店施工依頼書法©️

## 目的

AIやWork、Claude、GitHub作業へ渡すために、やること・やらないこと・対象・完成条件を明確にした施工依頼書へ変換する。

## 使う場面

- Web制作
- GitHub修正
- Notion整理
- アプリ改修
- 文章のヤスリ工程

## 入力

- 現状
- 対象リポジトリ
- 変更したい点
- 守るべき既存仕様
- 完成条件

## 出力

- そのまま貼れる施工依頼書
- 変更範囲
- 禁止事項
- 報告してほしい項目

## 手順

1. 対象を固定する。
2. 現在の基準を明記する。
3. 今回やることを番号で書く。
4. やらないことを書く。
5. 完成条件を書く。
6. 報告形式を書く。
7. そのままコピペできる形にする。

## コピペ用プロンプト

```text
この内容を明智工務店施工依頼書法©️で、対象、現在の基準、今回やること、やらないこと、完成条件、報告項目に分けて、そのまま貼れる施工依頼書にしてください。
```

## NG例

- お願い文だけにする。
- 対象ファイルを書かない。
- 完成条件を書かない。
- 既存仕様を巻き戻す危険を残す。

## 札

> 施工依頼はお願いではなく、作業範囲を固定する設計図。
