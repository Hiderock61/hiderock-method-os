# 011｜編集室発掘・作品札化法©️ v1.0

**サブタイトル：チャットログを本化手前まで掘る編集考古学。**

## 一行定義

> チャットログを要約するのではなく、原文を保存したまま発生史と系統樹を掘り、自然に形成された作品群を作品札へ昇格させる方法©️。

## 目的

大量のチャットログ、会話断片、旧メモ、途中案から、素材を要約して減らすのではなく、

**原文 → 発生史 → 差分 → 系統樹 → 作品群 → 作品札 → 作品化テスト**

の順で発掘し、本・短編・連載・企画などへ進められる「本化手前」の状態にする。

これは文章を書く方法ではない。

**何がすでに生まれているのかを発見するための方法**である。

## 何に使うか

編集室発掘・作品札化法©️は、**大量の会話・旧案・原文断片・没案の中に、すでに何個の作品が生まれているのかを見分けるために使う。**

短く言えば、

> **書く前に、何が作品なのかを発見する方法。**

長期チャットでは、素材が増えるほど次の問題が起きる。

- 面白い一文はあるが、それ単体で一作品なのか分からない。
- 初期案と現在案が混ざり、何を残すべきか判断しにくい。
- 一つの作品だと思っていたものが、実は複数作品へ枝分かれしている。
- 別ネタだと思っていたものが、実は同じ作品の衛星素材かもしれない。
- まだ形を決めない方が強い素材まで、早く名前を付けて潰してしまう。
- 全部が面白く見えて、一冊へ押し込みたくなる。

この方法では、そこでいきなり章立てや清書をしない。

原文と発生史を残したまま、素材を

- **独立作品群**
- **衛星素材**
- **混沌保留**

へ分け、独立できそうなものだけ作品札へ昇格させる。

つまり出力は完成作品ではない。

**編集会議ができる状態**である。

「何を書くか」を決める前に、

- 何がすでに一作品として立ち始めているか
- 何は別作品の周囲に置いた方が強いか
- 何はまだ名前を付けず保留した方がよいか
- どの作品から最小テストすれば素材を壊さないか

を見えるようにする。

## この方法が必要になるサイン

- 長いチャットにネタが増えすぎて、何から作品化すればいいか分からない。
- 「全部面白い」状態になって、一冊へ押し込みそうになっている。
- 昔の案と現在案のどちらが強いか分からない。
- 作品の境界が曖昧で、章立てすると何かが消えそう。
- 原文の変さや偶然生まれた言葉を、AIの綺麗な文章で潰したくない。
- 作品化する前に、素材同士の親子・枝分かれ・祖先を見たい。

## 何には使わないか

編集室発掘・作品札化法©️は、完成原稿を書く方法ではない。

また、

- 長いログを前後に再到達可能にする
- 一つの一文から新しい発見を増やす
- 一つの作品世界だけを長期運用する

こと自体も主目的ではない。

役割は、**回収済み・発生済みの大量素材を編集的に仕分けし、作品の境界と作品化優先度を発見すること。**

## 使う場面

- 一つの長いチャットルームに大量のネタが埋まっている。
- 面白い断片はあるが、何が一作品なのか分からない。
- 初期案と現在案が混在している。
- 昔の重要なアイデアが現在版で薄れている。
- 会話中に偶然生まれた言葉を失いたくない。
- 章立てや清書にはまだ早い。
- 一冊に押し込むと全部が平らになる。

## 四本柱

1. **未回収を残す**  
   分からない初出・接続・発生順を推測で埋めない。

2. **二重地図**  
   発生史の地図と、テーマ別素材棚の地図を別々に持つ。

3. **独立／衛星／混沌保留**  
   全素材を同格の作品へしない。

4. **最小作品化テスト**  
   最初から一冊を作らず、一群だけで単独火力を検品する。

## 入力

- 長期チャットログ
- 過去のまとめ
- 古い企画案
- 現在版
- メモ
- 会話中の断片
- タイトル案
- 没案
- 未分類素材

## 出力

- 原典保管庫
- 発生史
- 差分地図
- 系統樹
- テーマ別素材棚
- 独立作品群
- 衛星素材
- 混沌保留
- 作品札
- 未回収札
- 最小作品化テスト候補
- 編集会議ができる状態

## 手順

### 1｜原文保存

セリフ、ナレーション、広告、ニュース、タイトル、詩的断片、言い間違い、ネーミング、制作判断まで、発生時の言葉を優先して保存する。

この段階では要約・清書・作品化をしない。

### 2｜坂読み発生史

現在地から過去へ逆走し、

`この発明は直前の何から生まれたか？`

を一段ずつ追う。

判定は、必要に応じて以下へ分ける。

- 確定
- 有力
- 未確定
- 未回収

分からない場所を想像で埋めない。

### 3｜旧版↔現在版差分発掘

過去まとめと現在版を比較し、次を分ける。

- 昔は強かったが現在版で薄れたもの
- 現在版で新しく生えたもの
- 新発明の祖先

古い案は最新版で上書きせず、地層として残す。

### 4｜系統樹化

素材を一本の時系列だけでなく、

**何から何が枝分かれしたか**

で見る。

新しい設定を「追加ネタ」ではなく、既存ネタの進化形として読めるようにする。

### 5｜二重地図

#### 地図A｜発生史

何が何から生まれたかを見る作者用の地図。

#### 地図B｜素材棚

テーマ・領域別に見る制作地図。

一つの素材が複数棚につながってよい。

### 6｜作品群分離

#### 独立作品群

独自ルール・入口・出口・原文密度があり、単体で成立する。

#### 衛星素材

単独でも面白いが、別作品の周囲に置いた方が強い。

#### 混沌保留

まだ作品名や役割を確定しない方が強い素材。

保留は失敗ではなく、早期確定から守る保存状態。

### 7｜作品札化

独立作品群ごとに作品札を作る。

作品札の標準項目：

- 作品名
- 状態
- 既存原文
- 固有ルール
- 衛星素材
- 入口
- 出口候補
- まだ空欄
- 検品判定
- 作品化優先度

### 8｜横並び検品

「一番面白そう」ではなく、

**今すぐ作品化しても素材を壊さないもの**

を選ぶ。

見る項目：

- 単独火力
- 原文密度
- 世界説明の必要量
- 独自形式
- 未完成部分の大きさ
- 衛星素材への依存度

### 9｜最小作品化テスト

最初から完成版や一冊を作らず、一群だけ作品化して、

`この素材は本当に単独作品として立つか？`

を確認する。

必要なら隣接作品の素材を少量だけ衛星として混ぜる。

主役が入れ替わるほど混ぜない。

### 10｜テスト後検品

- 原文の異常さが残っているか。
- 説明を追加しすぎていないか。
- 読者が自力で気づける余白があるか。
- 衛星素材が主作品を食っていないか。
- 世界観説明なしでも成立するか。

必要なら次版では **追加より削除** を試す。

## 発生順と掲載順

> **発生順は作者用の地図。掲載順は読者用の舞台。混ぜない。**

作品が生まれた順番と、作品として読ませる順番は別でよい。

## 近接方法©️との役割分担

- **逆読みGo注釈法©️**：埋もれた原文・重要断片を発掘する。
- **往復線路法©️**：断片同士の前後接続を保存し、記憶なしで再到達できるようにする。
- **坂読み分岐法©️**：一つの断片から具体例・反例・別ジャンルへ横掘りし、新しい素材を増やす。
- **編集室発掘・作品札化法©️**：増えた素材全体を見て、作品境界・衛星・保留を判定し、作品札へする。
- **ROU-DOU編集方法©️**：この親方法を、ROU-DOUや刑務所世界観のような長期作品世界へ実装する複合編集運用。

## 工程上の位置

```text
長いログ
→ 逆読みGoで原文発掘
→ 往復線路法©️で接続保存
→ 必要な駅を坂読み分岐で横掘り
→ 編集室発掘・作品札化法©️で作品境界を発見
→ 独立作品群／衛星素材／混沌保留
→ 作品札
→ 最小作品化テスト
```

## NG例

- 最初に要約する。
- 最初に章立てする。
- いきなり清書する。
- 原文を綺麗な日本語へ直す。
- 古い案を最新版で上書きする。
- 発生順と掲載順を混ぜる。
- 全素材を一冊へ押し込む。
- 強い一文をすぐ「作品」にする。
- 未確定の発生史をAIが勝手に補完する。
- 未分類を失敗扱いする。
- 全部に意味を説明する。

## 実証例

ROU-DOUでは、

会話ログ
→ 原文回収
→ 坂読み発生史
→ 旧版↔現在版差分
→ 系統樹
→ 独立5群／衛星7群／混沌保留7群
→ 作品札5枚
→ 横並び検品
→ A3「犯罪体験広告」を最初の最小作品化テストに選定

まで進めた。

この実験により、巨大チャットログを**本化の一歩手前まで運べる再利用可能な編集工程**として成立した。

## 効果名

**作品境界発見・本化手前整理**

## コピペ用プロンプト

```text
このチャットログを「編集室発掘・作品札化法©️」で扱ってください。

いきなり文章化・章立て・清書をしないでください。

まず原文を保存し、現在地から過去へ坂読みして発生史を作ってください。

過去のまとめがある場合は、旧版と現在版を比較し、
「昔は強かったが薄れた素材」
「現在版で新しく生えた素材」
「新しく見える素材の祖先」

その後、素材同士の系統樹とテーマ別素材棚を作り、
「独立作品群」
「衛星素材」
「混沌保留」
へ分離してください。

独立作品群には作品札を作り、
作品名／既存原文／固有ルール／衛星素材／入口／出口候補／まだ空欄／検品判定／作品化優先度
を記録してください。

発生順と掲載順は分けてください。
分からない発生順は推測で確定せず、未回収札として残してください。

最後に作品札を横並びで検品し、
最初に「最小作品化テスト」をする1群を選んでください。
```
