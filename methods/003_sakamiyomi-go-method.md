# 003｜🚇逆読みGo注釈法©️

## 一行定義

> 長い会話を後ろから読み、重要な発話・発生源・原文ニュアンスを、要約で潰さず会話断片として発掘する方法©️。

## 目的

長い会話の中にすでに存在している重要情報を、現在地から後ろへ読みながら回収する。

単に会話を短くまとめるのではなく、

- どの一言が発生源だったか
- その時どんな言い方だったか
- 途中で何が反証・訂正されたか
- どの断片が後の作品・自分史・方法©️へ繋がったか

を、原文ニュアンスごと残す。

## 一言効果

**会話地層を後ろから掘り、重要断片と原文ニュアンスを回収する。**

## 何に使うか

逆読みGo注釈法©️は、**長い会話の中に埋もれた重要発言・発生源・原文ニュアンスを、後ろから一つずつ掘り出すために使う。**

短く言えば、

> **「あの大事な話、どこで生まれた？」を後ろから発掘する方法。**

会話が長くなると、現在地の結論だけは覚えていても、その結論がどう生まれたか、途中にどんな例や反例があったか、本人が最初にどう表現していたかが消えやすい。

逆読みGoは、その地層を後ろから掘る。

## この方法が必要になるサイン

- 長いチャットに重要情報が埋もれている。
- 「この考え、どこで最初に出た？」を探したい。
- 自分史・作品・方法©️の原典を回収したい。
- 要約すると消えそうな言い回しや原文ニュアンスがある。
- 現在の結論だけでなく、発生史まで残したい。
- 過去の反例・訂正・差分を拾い直したい。

## 何には使わないか

逆読みGoは、回収した断片同士へ前後接続を与えて、あとから記憶なしで往復できる線路を作ること自体を主目的にしない。

その仕事は **016｜往復線路法©️** の担当。

また、一つの発言から具体例・反例・別ジャンルへ横方向に新情報を増やす仕事は **012｜坂読み分岐法©️** の担当。

## 使う場面

- 会話が長く、どこに重要情報があるか分からない時
- 過去発話から自分史素材を回収する時
- 話の発生源をたどりたい時
- 作品や方法©️が自然発生した地点を探したい時
- 現在の理解へ至る途中の反証や訂正を拾いたい時

## 入力

- 長い会話ログ
- 発話断片
- 写真や動画に関する会話
- 現在地の話題
- 回収したい作品・出来事・方法©️の痕跡

## 出力

- 会話断片カード
- 逆読み番号
- 原文ニュアンス
- 本人側の構造
- 外部からの見え方
- 関連出来事札
- 札候補
- 未回収メモ
- 後続方法へ渡せる重要断片

## 手順

1. **現在地から会話を後ろへ読む。**
2. **重要断片を一つずつ拾う。**
3. **逆読み番号を付ける。**
4. **原文ニュアンスを保存する。**
5. **本人側の構造と外部からの見え方を必要に応じて分ける。**
6. **反証・訂正・差分も落とさない。**
7. **札候補や関連出来事を作る。**
8. **まずチャットへ出して検品する。**
9. **検品した同じ内容をNotionへ保存する。**
10. **必要なら往復線路法©️へ渡し、前駅｜この駅｜次駅の接続を作る。**
11. **気になる一文をさらに掘る場合は坂読み分岐法©️へ渡す。**

## 回答前ゲート

逆読みGoで回収し、反証済み・処理済みと確認された断片は、次の回答や推論でも参照する。

- 既に反証済みの一般論を、言い換えて再投入しない。
- 新しい根拠がないのに同じ議論を最初からやり直さない。
- 新情報が出た場合は、過去の回収断片と整合するか確認する。

このゲートの目的は結論を固定することではなく、**発掘済みの会話地層を次の推論の制約条件にすること**。

## 往復線路法©️との関係

2026-08-21、逆読みGo運用中に生まれた「前駅｜この駅｜次駅」「起点到達後の順読み検品」が独立し、**016｜往復線路法©️ v1.0** として正本化された。

現在の役割分担は次の通り。

- **逆読みGo注釈法©️ = 発掘**
- **往復線路法©️ = 線路敷設・再到達**
- **坂読み分岐法©️ = 横坑道採掘・新情報発生**

```text
長い会話
→ 逆読みGoで重要断片を発掘
→ 往復線路法©️で前後接続を作る
→ 必要な駅で坂読み分岐法©️を使い横へ掘る
→ 保存・編集方法へ渡す
```

## コピペ用プロンプト

```text
この会話を逆読みGo注釈法©️で整理してください。
現在地から後ろへ読み、重要断片を一つずつ拾ってください。
断片名、逆読み番号、原文ニュアンス、本人側の構造、外部からの見え方、札候補、関連出来事札、関連タグ、公開扱いに分けてください。

要約で潰さず、反証・訂正・差分・発生源を落とさないでください。
まずチャットへ出して検品し、検品後にNotionへ保存してください。

前後接続を作って再到達可能な線路にする必要がある場合は、往復線路法©️へ渡してください。
```

## NG例

- 会話をただ要約する。
- 原文ニュアンスを消す。
- 現在の結論だけ残して発生史を捨てる。
- 反例・訂正・横道を「重要ではない」と勝手に落とす。
- AIの記憶だけで原典を再現する。
- 発掘と線路敷設と横方向の深掘りを一つの方法へ全部押し込む。
