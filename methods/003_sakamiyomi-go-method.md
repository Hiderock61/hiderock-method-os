# 003｜🚇逆読みGo注釈法©️

## 一行定義

> 長い会話の中に既に存在している重要情報・発生源・経緯を、記憶に頼らず回収し、前駅｜この駅｜次駅の線路として保存して現在地まで再到達できるようにする方法©️。

## 目的

長い会話を後ろから読み、重要な発話や原文ニュアンスを会話断片として拾い、出来事札へ接続する。

さらに、保存した断片を単なる保管物ではなく、**次の回答や推論を拘束する外部記憶**として使う。

## 何に使うか

逆読みGo注釈法©️は、**長い会話の中に既に存在している重要情報・発生源・経緯を、記憶に頼らず回収し直すために使う。**

短く言えば、**「どうしてここまで来たんだっけ？」を、思い出さずに辿れるようにする方法**。

会話が長くなると、重要な発見そのものよりも、

- どの一言から始まったか
- 途中で何が反証されたか
- どの地点で意味が変わったか
- どの話題から現在地へ繋がったか

が失われやすい。

逆読みGoは、そこを**線路として保存し直す**。

## この方法が必要になるサイン

- 「これ、どこから始まった話だっけ？」となった。
- 長いチャットに重要情報が埋もれた。
- 同じ論点を何度もやり直している。
- AIが昔の反証済み一般論をまた持ってきた。
- 過去の会話から作品・自分史・方法©️の原典を回収したい。
- 記憶ではなく保存済みの経路で現在地へ戻りたい。

## 何には使わないか

逆読みGoは、新しいアイデアを大量に発生させるための方法ではない。
気になる一言を別ジャンルへ横展開することも主目的ではない。

**役割は、既に存在している情報を回収し、経路を復元し、後続推論の土台にすること。**

## 使う場面

- 会話が長く、どこに重要情報があるか分からない時
- 過去発話から自分史素材を回収する時
- 話の発生源をたどりたい時
- 既に通過した反証や判断を次回へ持ち越したい時
- 起点から現在地までの因果経路を再生したい時

## 入力

- 長い会話ログ
- 発話断片
- 写真や動画に関する会話
- 過去の検討結果
- 既に反証済みの論点

## 出力

- 会話断片カード
- 逆読み番号
- 前駅｜この駅｜次駅
- 関連出来事札
- 札候補
- 未回収メモ
- 順読み検品ログ
- 次の推論を拘束する通過済み論点

## 手順

1. 会話を後ろから読む。
2. 重要断片を拾う。
3. 逆読み番号を付ける。
4. 原文ニュアンスを保存する。
5. 本人側の構造と外部からの見え方を分ける。
6. 札候補を作る。
7. 前駅｜この駅｜次駅を接続する。
8. まずチャットへ出力して検品する。
9. 検品した同じ内容をNotionへ保存する。
10. 起点へ到達した後は、次駅を辿って順読み検品する。
11. 関連出来事札へリンクする。
12. 保存済み断片・反証・通過済み論点を、次回回答前に再参照する。

## 往復線路ルール©️

各駅に、可能な限り **前駅｜この駅｜次駅** を持たせる。

### 目的

記憶から「何だったっけ？」を思い出して検索するのではなく、保存済みの駅同士の接続を辿るだけで、起点にも現在地にも再到達できるようにする。

### 運用

1. 逆読み時は前駅を一駅ずつ辿る。
2. 各駅は、まずチャットへ出力して検品する。
3. 検品した同じ内容をNotionへ保存する。
4. 保存時に次駅／前駅の接続を残す。
5. 起点へ到達した後は、次駅を辿って順読みし、因果が切れていないか再検品する。
6. 固有名詞は検索目標にせず、線路上で自然に再発見する。
7. 空白・本文未回収区間も飛ばさず、未回収駅として線路上に残す。

## 回答前ゲート

逆読みGoで固定した断片・反証・通過済み論点は、次の回答や推論の前に再参照し、**後続推論を拘束する正本**として使う。

1. 新しい反論・説明を出す前に、関連する逆読みページを確認する。
2. 既に反証済み・処理済みの論拠を言い換えて再利用しない。
3. 新情報を出す場合は、どの通過済み駅を何の新根拠で通過できるのかを示す。
4. 新しい根拠がない場合は、同じ議論を再開せず現在地を維持する。
5. 目的は結論を固定することではなく、会話の地層を次の推論の制約条件に変えること。

## 坂読み分岐法©️との違い

- **🚇逆読みGo注釈法©️**：既に存在している会話から、失った経路・重要情報・起点を**回収する**。
- **🎢坂読み分岐法©️**：回収した一地点から、まだ存在していない具体例・反例・接続・概念を**発生させる**。

### 方向の違い

- 逆読みGo = **縦方向**。前駅・この駅・次駅を辿る。
- 坂読み分岐 = **横方向**。一つの途中駅から横坑道を掘る。

### 組み合わせ

```text
長い会話
→ 🚇逆読みGoで重要駅を発見
→ 🎢坂読み分岐でその一言をさらに掘る
```

## コピペ用プロンプト

```text
この会話を逆読みGo注釈法©️で整理してください。
後ろから重要断片を拾い、断片名、逆読み番号、原文ニュアンス、本人側の構造、外部からの見え方、札候補、関連出来事札、関連タグ、公開扱いに分けてください。
可能な限り前駅｜この駅｜次駅を接続し、起点到達後は次駅を辿って順読み検品してください。
既に反証済み・通過済みの論点は、次回推論の拘束条件として扱ってください。
```

## NG例

- 会話をただ要約する。
- 原文ニュアンスを消す。
- 断片を親カードへ戻さない。
- Notionに保存したのに次の回答前に見ない。
- 通過済みの一般論を、新しい言葉に着替えさせて再投入する。
- 空白区間や未回収駅を飛ばして経路をつなぐ。
