# 005｜上下俯瞰法©️

## 目的

出来事を上の層・中の層・下の層・横の層に分け、単なる感想や一文要約ではなく構造として見る。

## 使う場面

話が複雑で、制度・場所・感情・身体・社会的見え方が混ざっている時。

## 入力

- 複雑な出来事
- 会話
- 写真
- 人生断片

## 出力

- 上層
- 中層
- 下層
- 横層
- 次の作業方針

## 手順

1. 上の層として制度・社会・家族・法・資産を見る。
2. 中の層として場所・人・出来事を見る。
3. 下の層として体感・感情・欲求を見る。
4. 横の層として別レイヤーとの接続を見る。
5. 札または次の工程へ落とす。

## コピペ用プロンプト

```text
この素材を上下俯瞰法©️で整理してください。
上の層、中の層、下の層、横の層に分け、最後に札と次のNotion処理を出してください。
```

## NG例

- ただ感想を書く。
- ひとつの原因だけで説明する。
- 社会的見え方だけで止める。

## 札

> 上で構造を見る。中で出来事を見る。下で体感を見る。横で接続を見る。
