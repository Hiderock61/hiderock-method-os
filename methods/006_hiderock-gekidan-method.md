# 006｜ヒデロツク劇団方式©️

## 目的

複数の視点キャラを登場させ、ひとつの問題を感情・技術・デザイン・現実・創作など複数角度から検討する。

## 使う場面

- ひとつの答えに決めきれない時
- 議論を多角化したい時
- 企画やNotion設計を監査したい時

## 入力

- 議題
- 現状
- 迷っている点
- 判断材料

## 出力

- 各キャラ視点の発言
- 対立点
- 統合案
- 次の施工方針

## 手順

1. 議題を置く。
2. 必要な劇団員を出す。
3. それぞれの視点で発言させる。
4. 対立点を出す。
5. 明智君が統合する。
6. 次の工程へ落とす。

## コピペ用プロンプト

```text
この議題をヒデロツク劇団方式©️で検討してください。
必要な劇団員を出し、各視点の発言、対立点、統合案、次の工程に分けてください。
```

## NG例

- ひとりの視点だけで断定する。
- キャラ発言だけで終わる。
- 統合案を出さない。

## 札

> 劇団は混乱ではなく、複数視点を同じ舞台に乗せる装置。
