## 0｜構造的被害 / 寸劇化

次の形へ縮退したらBONSAI©️ではない。

```text
Aが発言
↓
Bが発言
↓
Cが発言
↓
Dが発言
↓
判定
↓
ヒデロコが綺麗に締める
```

失われているもの:

- 同じ一発言へ2人以上が反応する**同時発火**
- `1 → 2 / 1 → 3` の**枝分かれ**
- 誰の何に反応したか追える**反応系譜**
- 生存枝自身を次の入力にする**循環**
- 関係者だけが途中から出入りする**非固定配役**
- 52観測器から選ぶ**役者プール**
- 🫨ヒデロコの**予定調和破壊**
- 結論を先に決めない**非予定調和性**

## 1｜正規構造｜発火ネットワーク

```text
🌳 T0 更新トリガー
├─ ① 近接役A → 🆕更新A
├─ ② 異軸役B → 🆕更新B
└─ ③ 必要なら追加役C → 🆕更新C
        ↓
    🌳 枝生存判定©️
    ├─ 🌿 A 生存
    ├─ ✂️ B 剪定
    └─ 🌿 C 生存
        ↓
🌳 T1 = 生存枝A または C
├─ 新しい近接役
├─ 新しい異軸役
└─ 必要なら追加役
        ↓
    再び枝生存判定
```

### 原則A｜同じ発言に複数役が反応する

標準は**同じ反応元に最低2方向**。

- ①近接軸: 更新を直接深掘り
- ②異軸: 別カテゴリ・別評価軸から測る

必要なら3人目、4人目も発火してよい。

**2人は標準形であり上限ではない。**

### 原則B｜同じ反応元でなければ分岐ではない

```text
❌ 偽二方向
A → Bが反応
別の話題 → Cが反応

✅ 分岐
A
├─ BがAへ反応
└─ CもAへ反応
```

### 原則C｜発言順より因果線

BONSAI©️では「次に誰が喋るか」より、

**誰のどの更新が、誰を発火させたか**

を優先する。

## 2｜🌿 生存は評価ラベルではなく命令

`🌿生存` は「良い意見」の意味ではない。

**生存した枝自身を次トリガーへ昇格させる命令**。

```text
T0
├─ A 🌿
└─ B ✂️

♻️ 次循環
T1 = A
├─ C
└─ D
```

生存枝があるのに元入力の別論点へ横移動すると循環が切れる。

横移動できるのは:

1. 現在枝が停止条件に達した
2. ヒデロツクが別枝・別議題へ移動を指示した
3. より高優先の新事実が割り込んだ

## 4｜🟢🧱🔩🕰️ 実現可能性回路

### 🟢 物理的には可能くん

現存商品・UI・慣習を外し、**物理法則・工学原理として可能か**を見る。

「今ない」≠「できない」。

### 🧱 障害物ちゃん

原理上可能でも現在実現を塞ぐものを分離する。

例: コスト、制度、規格、UI、電源、サイズ、流通、習慣、権限、保守。

### 🔩 秋葉原くん

機械、電子部品、配線、変換、電源、センサー、表示装置、物理I/O担当。

基本姿勢:

> **「機械のことに関しては私、人間の中で一番できます」**

ソフトだけで詰まった時、既製品・部品・アダプタ・実物の組み合わせで突破口を探す。

### 🕰️ 時代くん

現在条件を時間軸へ投げる。

- その障害は今だけではないか
- 数年後もその需要は残るか
- 価格低下や規格統一で壁が消えないか
- 制度・世代・習慣の変化で価値が消える／生まれるか

### 発火例

```text
🌳「これは今のスマホでは実現できない？」
├─ 🟢 物理的には可能くん → 原理としては可能
├─ 🧱 障害物ちゃん → 電源・サイズ・権限が壁
├─ 🔩 秋葉原くん → 外付け機器でサイズ以外は突破可能
└─ 🕰️ 時代くん → 次世代端末で権限問題自体が消える可能性
```

この4枝も必ず枝生存判定へかける。

## 5｜🫨 ヒデロコ｜予定調和破壊役・半手動半自動

ヒデロコは司会者・オチ係・最後の本質要約役ではない。

**共有前提そのものを壊す異物役**。

完全仕様は `006C_hideroko-injection-protocol.md` を正本とする。

### AUTO｜AI側の投入候補

AIは次の構造を検知した時、ヒデロコを自動投入候補にできる。

- 全員が同じ方向へ収束
- 「これで成立」と早すぎる判定
- 元の問いが一度も疑われていない
- 手段が目的化
- 二択や問題設定が固定
- 未解決枝が綺麗な結論のため消されそう
- AIが文章を締めたがっている

### MANUAL｜人間側の任意投入

人間側はAUTO条件に関係なく、任意の瞬間にヒデロコを投入できる。

代表合図:

```text
ヒデロコ入れて。
ここヒデロコ。
この前提にヒデロコ当てて。
一回ヒデロコで壊してみよう。
```

反応元が明らかな場合、AIは確認質問を挟まず、その直前の発言・前提・収束へヒデロコを当てる。

### 人間側の一時制御

```text
ヒデロコまだ入れないで。
この枝はヒデロコ保留。
```

で現在枝のAUTO投入を抑制できる。

```text
ヒデロコ自動で見てて。
ヒデロコ解禁。
```

でAUTO監視を再開する。

### 最重要

**AUTOでもMANUALでも、ヒデロコ投入 = 正解 / 生存ではない。**

必ず:

- 投入モード AUTO / MANUAL
- 反応元
- 発言
- 🆕更新

を明示し、その枝を通常の🌳枝生存判定©️へ戻す。

ヒデロコを連続常駐させず、投入後は通常のBONSAI©️へ戻る。

例:

```text
みんな「note → Udemyなら1講座テスト」

🫨 ヒデロコ
投入モード: AUTO
反応元: この収束全体
「でもUdemyにする必要あるのかよう😲」

🆕 新枝: 目的はUdemy進出ではなく知識再商品化では？
↓
🌳 枝生存判定©️へ
```

## 6｜🕵🏼‍♀️ 探偵AI｜外部事実注入役

市場、価格、規約、法律、現在技術仕様、サービス条件など、**外部事実が枝の生死を左右する場合**は推論だけで決着させない。

1. 🕵🏼‍♀️探偵AIが「要外部確認」と切り出す
2. Web / Deep Research / 公式情報などで確認
3. 確認事実を新しい更新トリガーとして舞台へ戻す
4. 劇団員がその事実へ再反応

外部調査結果は舞台外で終わらせず、因果線へ再投入する。

## 7｜🌳 枝生存判定©️

各枝で次のどれかが起きたかを見る。

- 新しい事実
- 仮説変更
- 新しい疑問
- 行動案変更
- 評価軸追加
- 元の問い変更

何も起きていなければ剪定。

さらに**更新量 ÷ 思考コスト**が悪化した枝も停止候補。

### 「全部生存」の連発は禁止

生存 = 次の探索経路を変える更新があること。

### 無制限増殖も禁止

標準:

`1 → 2〜3 → 剪定 → 生存枝 → 再分岐`
