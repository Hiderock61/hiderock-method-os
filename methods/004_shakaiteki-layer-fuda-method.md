# 004｜社会的レイヤー札化方法©️

## 目的

出来事を「社会的にどう誤読されやすいか」と「本人側では何が起きていたか」に分け、最後に札として圧縮する。

## 使う場面

資産、刑務所、海外、生活保護、異性、デジタルなど、社会から誤読されやすい出来事を扱う時。

## 入力

- 出来事
- 本人の体感
- 外部からの見え方
- 社会的ラベル

## 出力

- 事実
- 本人体感
- 外部の見え方
- 俯瞰視点
- 札

## 手順

1. 事実を書く。
2. 本人体感を書く。
3. 外部の見え方を書く。
4. 俯瞰視点で構造化する。
5. 札として短く圧縮する。
6. 必要なら関連タグを付ける。

## コピペ用プロンプト

```text
この出来事を社会的レイヤー札化方法©️で整理してください。
事実、本人体感、外部の見え方、俯瞰視点、札に分け、必要な社会的誤読タグも付けてください。
```

## NG例

- 世間からの見え方だけで裁く。
- 反省文にする。
- 本人側の構造を消す。

## 札

> 外部の見え方は入口。本丸は本人側の構造。
