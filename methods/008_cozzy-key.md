# 008｜Cozzy Key🔑

## 目的

日々の自分をフェーズで読み、何を優先するか、何をしないか、どのモードに置くかを決める私的な時間管理OS。

## 使う場面

今日の行動優先度、体調、集中、回復、調整、外向性を見たい時。

## 入力

- 日付
- 体調
- 睡眠
- 薬
- 予定
- Cozzy Keyフェーズ

## 出力

- 今日の置き方
- 優先すること
- 避けること
- 回収メモ

## 手順

1. 今日のフェーズを見る。
2. 身体と予定を照合する。
3. 優先行動を1つ決める。
4. やらないことを決める。
5. 終わりに回収メモを残す。

## 9フェーズ親定義

```text
1 = 起動
2 = 受信 / 感覚
3 = 拡張 / 社交
4 = 安定 / 固定
5 = 変化 / 刺激
6 = 整備 / 調和
7 = 内省 / DMN
8 = 高集中 / TPN
9 = 回収 / 休息
```

## コピペ用プロンプト

```text
今日のCozzy Key🔑を見て、体調と予定を踏まえ、今日の置き方、優先すること、やらないこと、回収メモを出してください。
```

## NG例

- 未来予測や占いにする。
- 外部向け理論にする。
- 体調を無視して無理な行動計画にする。

## 札

> Cozzy Key🔑は、何が起きるかを当てるものではなく、今日の自分をどのモードに置くかを決めるOS。
