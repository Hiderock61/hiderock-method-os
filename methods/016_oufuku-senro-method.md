# 016｜往復線路法©️ v1.0｜思い出さず、接続を辿る

## 目的

長い会話や作業履歴を、記憶やキーワード検索に頼らず、各断片の前後接続を辿るだけで起点・現在地・途中経路へ再到達できるようにする。

> **思い出さない。線路を読む。**
> **逆読みは前駅、再生は次駅。**

## 発明の核

長いログでは、人間もAIも途中から「何の話だったっけ？」を記憶検索し始める。
すると、覚えている固有名詞・結論・印象だけが検索目標になり、途中の反例、横道、訂正、失敗、因果のつながりが落ちる。

往復線路法©️は、**記憶検索をやめ、接続情報だけを辿る**ための方法。

各断片を「駅」として、最低限次の3点を持たせる。

- **前駅**：どこから来たか
- **この駅**：いま何を回収しているか
- **次駅**：どこへ進むか

内容を思い出せなくても、接続が残っていれば線路だけで復元できる。

## 使う場面

- 長期チャットの再開・発掘
- 自分史ログ
- 制度・研究議論
- 制作プロジェクトの履歴
- バグ調査
- 編集履歴
- 意思決定ログ
- 長期の生活ログ
- 「あの話どこだったっけ」が増えた時

## 入力

- 長い会話ログ、制作ログ、調査履歴など
- 現在地
- 既に回収済みの駅があれば、その前駅／次駅情報
- 本文未回収区間があれば、その空白自体

## 出力

- `前駅｜この駅｜次駅` を持つ往復可能な駅ログ
- 起点→現在地の路線インデックス
- 未回収駅
- 起点到達後の順読み検品結果

## 基本原理

### 1｜記憶より接続

「豊島区だったっけ」「米だったっけ」と思い出そうとしない。
今いる駅の前駅を読む。
必要な固有名詞は、線路を辿る途中で自然に再発見する。

### 2｜各駅停車

重要そうな駅だけを抜かない。
変な例、訂正、失敗、メタ会話も、次の論点を生んだなら駅として残す。

### 3｜保存前レビュー

**チャット出力 → 検品 → Notion保存** の順番にする。

Notionへ先に黙って書くと、人間側が粒度・抜け・解釈ズレをその場で検品できない。

### 4｜逆走と順走を両方やる

- 逆読み：現在地 → 起点
- 順読み：起点 → 現在地

起点へ着いたら次駅を辿って順読みし、因果が切れていないか再検品する。

### 5｜空白も駅

本文未回収、日付の飛び、取得できない発言も消さない。

**「ここは未回収」という情報自体が線路情報。**

## 手順

1. **現在地を1駅として固定する。**
2. **1駅だけ前へ戻る。**
3. **その駅をまずチャットへ出力する。**
4. **人間側が見える状態で粒度・抜け・ズレを検品する。**
5. **検品した同じ内容をNotionへ保存する。**
6. **保存時に `前駅｜この駅｜次駅` を残す。**
7. **同じ操作を起点まで各駅停車で繰り返す。**
8. **固有名詞や結論を検索目標にしない。**
9. **起点へ着いたら次駅を辿って順読みする。**
10. **因果が切れた地点、飛躍、誤接続を修正する。**
11. **新駅を追加した時は直前駅との接続も更新する。**

## 情報構造

```text
[前駅]
   ↓
[この駅]
   ↓
[次駅]
```

全体は、

```text
起点 → 駅1 → 駅2 → 駅3 → … → 現在地
 ↑                              ↓
 └──────── 逆読み可能 ────────┘
```

## 逆読みGo注釈法©️との関係

- **逆読みGo注釈法©️ = 発掘**
- **往復線路法©️ = 線路敷設**

逆読みGo注釈法©️は、長い会話から重要断片と原文ニュアンスを回収する。
往復線路法©️は、その回収断片へ前後接続を与え、あとから記憶なしで再訪・再生できるようにする。

## NG例

- 記憶からキーワードを思い出して検索する
- 固有名詞を目的地にする
- 重要そうな駅だけ抜く
- 複数駅を一括要約する
- チャットに出さずNotionへ先に書く
- 空白・未回収区間を無かったことにする
- 前後接続を残さず孤立メモにする
- 起点へ着いて終わり、順読み検品をしない

## 実証｜2026-08-21

「生活保護×menu au PAY」の長い議論で実施。

途中では「豊島区」が記憶アンカーとして出たが、固有名詞検索をやめ、一駅ずつ戻った。
その結果、現物米、クラッカー、Ponta、暗号資産、ヴィンテージギター、CW裁量、LoGoフォームなどが順番の中で自然に再発見された。

最終的に、このルームの起点である、

> **「Notionにもう書いてあるんだから、まずそれを参照してから答えて」**

へ到達。

その後、起点から現在地まで42駅を順読みし、記憶検索を使わず因果経路を再生できた。

## 終了条件

- 起点に到達した
- 起点から現在地まで順読みできた
- 各駅の前後接続が切れていない
- 未回収区間が未回収として明示されている
- 固有名詞を思い出して検索しなくても再到達できる

```text
このログを往復線路法©️で処理してください。

固有名詞や結論を検索目標にせず、起点まで到達したら次駅を辿って順読みし、因果が切れていないか検品してください。
```
