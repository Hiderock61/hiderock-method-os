# 010｜方法©️登録プロトコル

## 目的

新しい発明や手順が会話中に生まれた時、それを一時的な会話で終わらせず、方法©️として言語化し、方法コレクションへ登録できる形にする。

## 使う場面

- 新しい整理方法を思いついた時
- 既存の方法©️が進化した時
- 別の部屋や別AIでも再現したい時
- 長期記憶に頼らず、方法を外部化したい時

## 入力

- 発明のきっかけ
- 方法名候補
- 目的
- 手順
- 実例
- NG例
- 既存方法©️とのつながり

## 出力

- 方法名
- 目的
- 使う場面
- 入力
- 出力
- 手順
- NG例
- コピペ用プロンプト
- 系譜メモ

## 標準合図

```text
これ、方法©️候補。
言語化して、方法コレクションDB｜ヒデロック発明OS©️に入れて。
目的・使う場面・入力・出力・手順・NG例・コピペ用プロンプトまで作って。
```

## 短縮合図

```text
方法©️登録。
```

## 既存方法の進化時

```text
〇〇法©️のv0.2として追補して。
```

## 系譜を見る時

```text
この方法©️の系譜も整理して。
```

## 別AIへ渡す時

```text
この方法©️をコピペ用プロンプトにして。
```

## NG例

- 名前を付けずに会話の中で流す。
- 目的や使う場面を書かない。
- 手順だけでNG例を書かない。
- 既存方法©️とのつながりを見ない。

## 札

> 方法©️は、発明した瞬間に名前を付けると、次から呼び出せる。
