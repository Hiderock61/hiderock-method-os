# 対話回収法©️ v2.0｜呼び出しプロンプト

## 通常回収

```text
この会話を「対話回収法©️ v2.0」で回収してください。
最初に methods/017_taiwa-kaishu-method.md を読み、正本仕様に従ってください。

作品化の前に、
1. 対象範囲と原典固定
2. 発言者別の時系列台帳
3. 主要命題の履歴
4. 転換発言の原文固定
を行ってください。

その後、誰が何を言ったかを明示した対話Sceneと後発AI解説へ編集し、最後に原典照合の回収漏れ監査を行ってください。
AIの誤読・撤回・本人の「違う」「そこじゃない」を削らないでください。
```

## 劇団回収モード

```text
この会話を「対話回収法©️ v2.0｜劇団回収モード」で回収してください。
最初に methods/017_taiwa-kaishu-method.md と methods/006_hiderock-gekidan-method.md を読んでください。

通常の時系列台帳・命題履歴に加えて、
反応元、枝ID、親トリガー、役名、観測軸、近接/異軸、🆕更新、🌿生存/✂️剪定、判定理由、次トリガー化、⚔️未解決対立、🧬採用系譜、🎬幕理由
を記録してください。

時系列だけでA→B→C→Dの一本道に潰さず、BONSAI©️の木構造を残してください。
完成後に回収漏れ監査と枝系譜監査を行ってください。
```
