# method-registration-prompt.md

新しい方法©️を登録するためのコピペ用プロンプト。

```text
これは新しい方法©️候補です。
以下の素材を読んで、方法名を仮で付け、方法カードとして整理してください。

出力項目：
- 方法名
- 目的
- 使う場面
- 入力
- 出力
- 手順
- Notion項目
- 関連タグ
- コピペ用プロンプト
- 実例
- NG例
- 関連プロジェクト
- 公開扱い
- 状態
- 既存の方法©️との系譜

注意：
- いきなりエッセイ化しない。
- 個人情報や公開注意素材は公開向けに薄めず、まず私的保管として扱う。
- 方法©️として再実行できる形にする。
- 必ずNG例も作る。
- 最後に短い札を作る。

素材：
ここに会話やメモを貼る。
```
