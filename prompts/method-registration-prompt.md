# invention-registration-prompt.md

新しい発明品を登録するためのコピペ用プロンプト。

旧称：method-registration-prompt.md

```text
これは新しい発明品候補です。
以下の素材と原典を読んでください。

最初に、これを自動的に「方法©️」と呼ばず、発明種別を判定してください。

判定候補：
- 🤖 AI方法©️：入力を渡せばAIが主要処理を開始できる
- 🤝 協働方法©️：AI処理と人間側の実機・現実行動の往復で成立する
- 🔑 OS：生活や作業全体の置き方を決める運用体系
- 🧰 プロトコル：正本・登録・復旧など仕組みを守る規則
- 🧭 ガイド：人間が現実で動くための探索・行動アドバイス。AIは補助役

主判定：
「〇〇でやって」と言われた時、AIがその場で主要処理を開始できるか？

出力項目：
- 発明品名
- 発明種別
- 判定理由
- 一言効果
- 何に使うか
- 誰が実行するか
- AIができること
- 人間側が必要なこと
- 目的
- 使う場面
- 入力
- 出力
- 手順または運用規則
- Notion項目
- 関連タグ
- コピペ用プロンプト（必要な場合）
- 実例
- NG例
- 関連プロジェクト
- 公開扱い
- 状態
- 既存発明品との系譜

種別別の注意：
- AI方法©️：再実行できる入力／処理／出力／NGを作る。
- 協働方法©️：AI側／人間側／往復点／実機確認を分ける。
- OS：単発処理へ縮小せず、状態・優先・非優先・回収を残す。
- プロトコル：守る規則・復旧条件・禁止事項を中心にする。
- ガイド：人間側の行動、AIが補助できること、AIができないことを明示する。

共通注意：
- いきなりエッセイ化しない。
- 個人情報や公開注意素材は、まず私的保管として扱う。
- 原典を確認せずAIの記憶から正本化しない。
- 必ず「何に使うか」を生活語で書く。
- 最後に短い札を作る。

素材：
ここに会話やメモを貼る。
```
