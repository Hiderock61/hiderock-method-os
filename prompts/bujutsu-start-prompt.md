## 別部屋用・確実版

```text
この問題を武術テンプレ法©️ v1.6で扱ってください。

最初に GitHub リポジトリ Hiderock61/hiderock-method-os の BUJUTSU_START_HERE.md を読んでください。
続けて以下を確認してください。

1. methods/014_bujutsu-template-method.md
2. methods/014_bujutsu-template-method-v1.2-jutsu-supplement.md
3. methods/014_bujutsu-template-method-v1.3-judo-supplement.md
4. methods/014_bujutsu-template-method-v1.4-taikyokuken-supplement.md
5. methods/014_bujutsu-template-method-v1.5-karate-supplement.md
6. methods/014_bujutsu-template-method-v1.6-systema-supplement.md

武術テンプレ法©️は、格闘家キャラクターが順番に意見を言う方法ではありません。
同じ素材を固定し、流派ごとの『作用点』を切り替えて、分析・議論・制作・修理・意思決定の差分を作る方法です。

まず相撲型で、
【共通素材】
【今回の目的】
【土俵内】
【場外】
【開始状態】
【目的状態】
を固定してください。

次に、今の問題で『何を動かす必要があるか』を判定し、作用点に合う流派を選んでください。
流派は雰囲気で選ばず、
【作用点】何を動かすか
【操作】どう動かすか
【結果】何が変わるか
で認定してください。

根拠・事実・反証が必要なら柔術型。
使用者の現在認識を次の一手まで運ぶなら柔道型。
前流派の出力を次流派へ渡すなら太極拳型。
最終出力を一文・一操作へ圧縮するなら空手型。
問題設定そのものを問い直すならレスリング型。
対立を比較するならボクシング型。
相手がすでに出した反論・反応を利用するなら合気道型。

v1.6のシステマ型は常駐観測層として、実行後に、
【現在観測】
【目的との差】
【現在作用点】
【継続／切替】
【次の一手】
【次の再観測点】
を再判定してください。

最初に選んだ流派へ固執しないでください。
作用点が変わったら流派を切り替え、切替時は太極拳型の接続規格で保持情報を次へ渡してください。
全流派を順番に一回ずつ使うことは禁止です。
武術名を装飾や口調として使わないでください。
制作上の比喩を、武術の歴史的・科学的事実として断定しないでください。

最後は、必要なら空手型で
【現在状態】
【推奨流派】
【理由】
【次の一手】
まで圧縮してください。
```

## 議論・企画検討に使う時

```text
この企画を武術テンプレ法©️ v1.6で議論してください。
ただし『格闘家が討論する寸劇』にはしないでください。
同じ企画素材を固定し、相撲で争点と場外を決め、必要ならレスリングで前提を壊し、柔術で事実・根拠・反証を積み、ボクシングで残った案を対置し、柔道で次の一手へ運んでください。
この順番は固定ではありません。システマ型で現在の作用点を監視し、必要な流派だけ使ってください。
```

## BONSAI©️と併用する時

```text
まずBONSAI©️で一つの更新トリガーへ複数観測器を当てて枝を作ってください。
その後、掘る価値がある🌿生存枝を一つ選び、その枝だけを武術テンプレ法©️ v1.6へ渡してください。
武術テンプレ側では共通素材をその生存枝に固定し、現在の作用点に合う流派で深掘りしてください。
BONSAIの配役ネットワークと武術テンプレの流派切替を混同しないでください。
```
