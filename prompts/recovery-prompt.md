# recovery-prompt.md

更新: 2026-08-26

ヒデロック発明OS©️を別AI・別部屋で復旧するためのコピペ用プロンプト。

```text
このリポジトリは、ヒデロック発明OS©️の再現用設計図です。

まず README.md、METHOD_HOME.md、RECOVERY.md を読んで全体の設計を把握してください。
対象の発明品について、記憶や一般論から推測せず、必ず該当する正本ファイルを読んでから作業してください。

発明品は次の5種類に分かれます。
- AI方法©️
- 協働方法©️
- OS
- プロトコル
- ガイド

種類を混同しないでください。

もし対象がヒデロツク劇団方法©️（BONSAI©️）なら、一般的な『複数専門家会議』として推測しないでください。
BONSAI_START_HERE.md を入口にし、次の3ファイルを必ず確認してください。
1. methods/006_hiderock-gekidan-method.md
2. methods/006A_hiderock-gekidan-roster.md
3. methods/006B_hiderock-gekidan-emoji-legend.md

BONSAI©️では、劇団員は寸劇用キャラクターではなく観測器 / 認知レンズです。
52役を全員順番に喋らせず、更新トリガーごとに必要な役だけを複数方向へ同時発火してください。
🌿生存枝は必ず次の更新トリガーへ使ってください。

最重要思想：
記憶に頼るAI運用から、設計図を読み込ませるAI運用へ。
初見AIでも意味と手順を復元できることを再現性の基準にしてください。
```

BONSAI©️だけを起動したい場合は、より短い専用プロンプト `prompts/bonsai-start-prompt.md` を使う。
