## 採用論文

### 1. Maier et al. 2026

**A meta-analysis of the effect of generative AI on productivity and learning in programming**

- 23 studies
- 27 effect sizes
- productivity: Hedges' g = 0.33
- 95% CI = 0.09–0.58
- controlled experimentsで効果が大きめ
- open-source / enterpriseでは効果が小さめ
- learning outcomeは統計的有意差なし

### 2. Gurgul et al. 2026

**The State of Generative AI in Software Development: Insights from Literature and a Developer Survey**

- systematic literature review + 65 developers
- design / implementation / testing / documentationで高い効果
- planning / requirements analysisは低め
- skill erosion / technical debt / oversightが論点
