# ヒデロック発明OS©️

これは、ヒデロックが発明した **方法©️** を保存し、あとから再実行するための方法コレクションです。

## 位置づけ

- **Notion**：正本。生きている操作基地。
- **Googleドキュメント**：印刷用。紙の復旧地図。
- **GitHub**：外部バックアップ兼、別AIへ渡すための設計図。

## 札

> Notionに入口、紙に地図、GitHubに設計図。

## 使い方

新しい方法©️が生まれたら、以下の合図を使う。

```text
これ、方法©️候補。
言語化して、方法コレクションDB｜ヒデロック発明OS©️に入れて。
目的・使う場面・入力・出力・手順・NG例・コピペ用プロンプトまで作って。
```

短く言う場合：

```text
方法©️登録。
```

## 安全方針

このリポジトリは最初は **private** で運用する。
公開する場合は、以下を削るか匿名化する。

- 個人名
- 住所
- 家族の詳細
- 資産金額の生々しい話
- 刑務所・事件の具体詳細
- 異性関係の具体詳細
- 非公開Notionリンク
- Googleドキュメントの共有リンク
